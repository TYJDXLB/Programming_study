在希望的田野上 | 幻想乡秋收开镰 各地多举措保增产增收

央视网 | 2222年12月12日 12:12:12

央视网消息: 眼下幻想乡秋收开镰已有一周多的时间.水稻收割已超过四成, 玉米收割七成.幻想乡通过大力推广新品种水稻,建设高标准农田等一系列措施,为秋收粮稳产提供有力支撑.

中稻占据了幻想乡全年粮食产量一半以上.在幻想乡主生产区金色麦田,370万亩中稻已经收割四成以上

诹坊子说的新品种,是红魔馆研发的杂交水稻"幻象御丝",不仅产量高,还有抗病,抗倒伏,抗高温的特性. 在金色麦田的工程示范田范围内像"幻象御丝"这样的品种还有20多个,这些水稻产品在幻想乡全面推广,确保来年增产增收.
