# 网页制作步骤

## 项目目录
项目根目录是存放网站网站的第一层文件夹, 内部包含网页的所有素材, 包含HTML, CSS, 图片, JavsScript等等.

文件夹结构:  
* 根目录
    * images文件夹: 存放固定使用的素材(例如: logo, 样式图等等)
    * uploads文件夹: 存放非固定使用的素材(例如: 商品图, 宣传图等需要上传的图片视频素材)
    * CSS文件夹: 存放CSS文件(用link标签引入)
        * base.css: 基础公共样式(例如: 清除默认样式, 设置网页基本样式等等)
        * 各个页面.css: 存放各个页面的CSS样式(首页就叫index.css)
    * HTML文件: 存放各个页面的HTML代码
    * Readme.md: 说明文档(可有可无)

## 网页制作思路
1. 布局思路:先整体再局部, 从内到外, 从上到下, 从左到右
2. CSS实现思路:
    1. 画盒子, 调整盒子范围(宽高背景色)
    2. 调整盒子位置(flex布局, 内外边距)
    3. 控制图片, 文字样式

## 网页制作具体步骤

### 引用CSS文件
网页结构完成之后一定要用 `<link>` 语句引入CSS文件(一定要先引入base.css清除默认样式, 再引入新样式.css)

### 头部区域(hander)制作
hander标签结构:  
* 通栏(宽度与浏览器窗口相同的盒子)
    * 版心
        * logo: 单机跳转到首页, 搜索引擎优化. 标签结构: h1>a>网站名称(搜索关键字, 一般都把字体尺寸设置为0用来隐藏字)
        * 导航: 点击跳转页面. 标签结构: ul>li*3>a(使用li嵌套a标签, 避免堆砌a标签, 使网页搜索降级)
        * 搜索: 标签结构: .search(由于两个标签同一行排列因此需要disply: flex一下)>input + a/button
        * 用户: 标签结构: .user>a>img+span

### banner区域制作
banner标签结构:  
* 通栏banner
    * 版心
        * 内容(如果分左右结构的话要分开制作)
* banner左侧导航: 标签结构: .left>ul>li*9>a
* banner右侧课程表: 标签结构: .right>h3+.content

### 精品推荐(recommend)区域制作
recommend标签结构: .recommend>h3+ul+.modify(a)  
布局思路: flex布局

### 精品课程区域(course)
course标签结构: .hd+.bd  
布局思路: 盒子模型

### 前端开发工程师区域
标签结构:左右结构(大部分可以用上个步骤的公共部分制作)
