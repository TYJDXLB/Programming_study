#### Ollama安装
> Ollama是一个在本地运行，管理大语言模型的工具。官网：https://ollama.com/

下载之后先不要直接安装，如果想改变ollama安装位置在安装文件路径下打开cmd，输入：
```
OllamaSetup.exe/DIR=要安装的位置
```
安装之后在设置里可以配置大模型的下载地址

#### Ollama使用(下载本地模型并调用)
> 查看ollama相关命令:  `Ollama --help`

打开Ollama官网，点击model选项，根据电脑配置选择合适的模型。复制下载代码(我部署的deepseek-r1,1.5b模型代码示例 `ollama run deepseek-r1:1.5b`)运行之后等待下载完毕即可使用

### 网络基础知识
IP地址：可以理解为设备在互联网上的地址（唯一身份证）[IPv4地址：32位二进制；IPv6地址：128位二进制]
```
127.0.0.1   为特殊IP地址，表示本机地址(本地回环地址)
```
域名：由一串用点分隔的字符构成，由于IP地址不方便记忆因此设计了域名，并通过DNS对IP地址和域名相互映射(相当于号码本)
```
localhost   为本机域名
```
端口号(Port)：是整数，取值范围0-65535，用来表示计算机在设备中运行中的程序(默认端口号：HTTP协议默认为80；HTTPS默认为443)

HTTP(Hyper Text Transfer Protocol超文本传输协议)规定了客户端与服务器之间的传输规则。特点：
* 基于文本的协议：请求和响应部分的协议内容为文本格式，底层通过TCP协议传输，稳定性强
* 基于请求-响应模型：一次请求对应一次响应，必须由客户先发送请求，服务器端再响应。
* 无状态：服务端不会记忆与客户端的历史交互信息，每次响应都是独立的。

HTTP协议中请求及响应的数据结构：
* 请求格式：请求行(请求方式[GET小请求在请求行中可以完成不同参数间用&连接；POST大请求在请求体中请求]，资源路径)、请求头(key:value)、请求体(post方式)
* 响应格式：响应行(状态码[200为正常响应，4开头表示客户端问题，5开头为服务器问题])、响应头(key:value)、响应体

国际ISO组织统一了网络通信的模型和标准：
* OSI七层网络模型
* TCP/IP四层网络模型

JSON(JavaScript Object Notation)是前端的一种对象表示方法。表示形式类似python中的字典，都是键值对的形式，不过所有的key都必须使用双括号引起来，值可以是任意类型。

python安装模块：安装完python之后会自带一些python内置模块被称为python标准库，如果要用到一些第三方模块都是放到远程仓库(PyPI)中的 要下载第三方模块的时候就可以用pip下载

### Apifox(一款API设计、开发、测试的一体化协作平台，项目测试接口神器)
在使用大模型API时先看提供的API文档，其中cURL为命令行调用，其中curl开头的为请求行，-H开头为请求头，-d开头为请求体(存放JSON格式内容)  
按照示例代码使用apifox，如下：
```
curl -X POST "https://open.bigmodel.cn/api/paas/v4/chat/completions" \请求方式选择POST 地址填双引号中的地址
-H "Content-Type: application/json" \
-H "Authorization: Bearer YOUR_API_KEY" \请求头，在Headers选项内填上相应的键值对
-d '{
    "model": "glm-5.3",
    "messages": [
        {   // 系统提示词，设定AI的回答风格，限制，规则等
            "role": "system",
            "content": "你是一个有用的猫娘AI助手，回答任何问题时结尾都会带一个'喵~'，请用温柔可爱的语气回答用户的问题"
        },
        {   // 用户提示词 用户实际提出的问题
            "role": "user",
            "content": "你好，请介绍一下自己。"
        }
    ],
    "temperature": 1.0,
    "stream": true \是否使用流式回答(逐个个token的响应回答信息)
}' \请求体，在Body选项中选择JSON格式把代码粘贴进去
```
之后点击发送即可进行请求，结果如下：

### Python代码调用
由于API_key比较重要，因此可以将其配置到环境变量里面，使用的时候直接使用变量名即可调用。
> 右键此电脑点击属性，选择高级系统设置点击环境变量，在用户变量中新建一个环境变量。自己取一个变量名，变量值设为你的api_key

安装第三方包：(以openai为例)
```
安装软件包(最新版)：pip install openai
安装软件包(指定版本)：pip install openai=版本号
卸载软件包：pip uninstall openai
列出已有包：pip list
查看包详情：pip show openai

进行操作时为了防止环境错误可以：地址 -m 操作
```

> 开源的python库，专为数据工程师及机器学习工程师设计，用于快速基于python代码构建交互式的web网站(无需前端技术)
