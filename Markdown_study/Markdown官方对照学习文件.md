## 快速上手

编辑器支持完整的 **Markdown** 语法，以下是一些示例：

### 文本格式

- **粗体文本** 使用 `**双星号**`
- _斜体文本_ 使用 `_下划线_`
- ~~删除线~~ 使用 `~~波浪线~~`
- `行内代码` 使用反引号

### 列表

无序列表：

- 第一项
- 第二项
  - 嵌套项 A
  - 嵌套项 B
- 第三项

有序列表：

1. 规划文档结构
2. 编写内容
3. 预览并下载

```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

print(list(fibonacci(10)))
```
