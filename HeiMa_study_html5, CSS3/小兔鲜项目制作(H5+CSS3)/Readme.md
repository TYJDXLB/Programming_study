## 小兔鲜项目示例
>该项目示例仅使用 HTML5 + CSS3制 作不涉及到 JavaScript 语言使用

### 项目结构
* 根目录文件夹
    * images 文件夹: 存放固定图片素材.
    * uploads 文件夹: 存放非固定素材.
    * iconfont 文件夹: 存放字体图标素材.
    * css 文件夹: 
        * base.css: 基础公共样式.
        * common.css: 各个网页相同模块的重复样式,例如: 头部,底部
        * index.css: 首页CSS样式
    * index.html: 首页HTML文件.

### 相关知识点&注意事项
#### 一. SEO三大标签(搜索引擎优化,提升网站搜索排名)
常见提升SEO的方法:  
1. 竞价排名(花钱)
2. 将网页后缀设置为html
3. 标签语义化(合适的地方使用合适的标签)

### 二.Favicon图标
网页图标出现再标题栏中,增加网页辨识度.图标:favicon.ico, 一般放在网页根目录中.
