/* 1.ref参数 （引用传递）
作用：将一个变量传入一个函数中进行"处理"，"处理"完毕后再把"处理"后的结果代出
【函数外必须为变量赋值，而函数内可以不赋值】
语法：形参，实参前面加上ref
static void add(ref int num)
add(ref num); */
/* 2.out参数
作用：一个函数中需要返回多个不同类型的值，用out参数
【函数外可以不为变量赋值，函数内必须为变量赋值】
语法：
stastic void number(int a, int b, out int max, out int ming)
number(a, b, out max, out min) */

/* 函数：访问修饰符：
应用场合：一、修饰类：public，internal（默认）
二、修饰类成员：（五种均可，不写为默认private）
    1. static 关键字：用于修饰 类，字段，属性，方法，构造方法
        被static修饰的类为 静态类；
        被static修饰的类成员为 静态类成员：
            （1）静态字段 不属于任何对象只属于类，访问需要：类名.静态字段名(可重新赋值 类名.静态字段名 = 值；储存的数据再内存中只有一份)
            （2）静态属性 对静态字段进行封装保证其合法性 访问需要：类名.静态属性名(不能封装非静态对象)
            （3）静态普通方法 调用需要：类名.方法名(静态方法中不能调用静态方法)
            （4）静态构造方法 用于初始化静态成员，一个类中只能有一个，该方法没有访问修饰符，没有参数，可定义在(非)静态类中
            （5）静态类 类中成员全部为静态成员，声明需要在class前加上static
【先生成静态成员，后有实例成员；后出现的可以调用先出现的，先出现的不能调用后出现的】 */

/* 设计模式：
一、单列(设计一个类时，整个程序运行期间只有一个实例对象)设计模式：（用于非静态类）
步骤：1.声明一个静态且私有的当前类型的字段 private stastic ClassName instance;
     2.创建私有无参的构造方法，保证外边无法实例化该类 private ClassName() {}
     3.创建一个静态方法，用于创建此类的唯一对象（返回值为当前类的类型）
     public stastic ClassName Instance() {
        if (instance == null){
            instance = new ClassName();
        }
        return instance;
     }
二、嵌套类 把一个类定义在另一个类的内部中；外边的叫外部类，里面的叫嵌套类(嵌套类与普通类相同，只是位置不同)
    实例化：外部类名.内部类名 （person.web a = new person.web();
三、匿名类 如果某个类的实例对象只会用一次，可以使用匿名类创建这个对象，不用定义类即可创建一个对象（这个类一般用于储存只读属性）
    语法：var p = new { Name = "monkey", Age = 100};
    输出：Console.WriteLine("姓名：{0}年龄：{1}", p.Name, p.Age); 因为是只读的所以不能重新赋值
四、密封类 被sealed的类不可被继承，不能有子类 */
