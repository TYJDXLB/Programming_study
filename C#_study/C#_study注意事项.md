# 记录C#的一些学习经验和问题

## 一、不能直接新建C#文件运行，需要创建正式项目
- 在下方终端输入
```
dotnet new console -n 项目名称
```
建立一个控制台项目，在项目的Program.cs文件里写代码；

## 二、点击调试按钮不生效
> 不生效原因：C#特别娇气项目莫名关闭或改变（例如：1.调试完没有关闭产生的 *终端和.exe窗口* 就直接关闭或者再次调试；2.没有把VScode全部关闭直接切换并打开别的文件(不是该解决方案的.cs文件)）会产生僵尸进程影响后续调试。

解决措施：
1. 结束僵尸进程：按Ctrl+Shift+ESC打开任务管理器，在详细信息中搜索"dotnet"结束掉所有相关进程。
2. 打开项目文件夹，删除掉"bin","obj"里面的所有文件，如果有删不掉的就去确认下上一步进程是不是完全结束掉了，如果结束了是在删不掉就算了。
3. 进入VScode运行Program.cs的调试系统等待加载完毕即可。

> 注意：要编写其他文件时一定要把调试产生的 *终端和.exe窗口* 全部关掉，并且把.cs文件也关掉再打开别的文件。如果要切换文件夹则最好再打开一个VScode，不然大概率会出问题。
